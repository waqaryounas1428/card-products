# ZUNIQUE — Fashion Store

A modern e-commerce website for fashion products including dresses, watches, and shoes.

---

## Pages

| File | Description |
|------|-------------|
| `index.html` | Main homepage with products, hero banner, newsletter & footer |
| `buy.html` | Checkout page with customer info & payment form |
| `success.html` | Order confirmation page |
| `order-details.html` | View, edit or delete recent order |

## Styling

| File | Used By |
|------|---------|
| `new.css` | index.html |
| `buy.css` | buy.html |
| `success.css` | success.html |
| `order-detail.css` | order-details.html |

## JavaScript

| File | Description |
|------|-------------|
| `index.js` | `goToBuyPage()` navigation function |
| `stroge.js` | Saves order data to localStorage |

---

## Features

- Promo ticker banner at the top
- Hero banner with sale overlay
- Product cards with Add to Cart & Buy buttons
- Cart counter badge in header
- Toast notification on add to cart
- Category filter buttons
- Back to top button
- Newsletter subscription form
- Order flow: Buy → Success → Order Details
- All data stored in localStorage (no backend needed)

## Product Categories

- Women Dresses (Sharara, Lawn, Embroidered)
- Men Stitched Dress (Kurtas)
- Men Watches
- Men Shoes

## Color Theme

- Primary: `#7c3aed` (Purple)
- Accent: `#a855f7` (Violet)
- Background: `#f5f0ff` (Soft Lavender)

## How to Run

Just open `index.html` in any browser — no server or install needed.
